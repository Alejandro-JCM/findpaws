# FindPaws 
Plataforma de rescate y adopción de mascotas

## Descripción
Sistema para reportar mascotas perdidas, encontradas y facilitar adopciones.

## Tecnologías
- Frontend: React, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB
- Geolocalización: Google Maps API

## Instalación
```bash
npm install
npm run dev
